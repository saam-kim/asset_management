# 📈 Edu Life-Balance Simulator (생애 재무설계 & 자산관리 시뮬레이터)

본 프로젝트는 중·고등학생들이 게임 요소를 통해 인생의 **꿈(버킷리스트)**, **현실의 지출(현금 흐름 수조)**, **노후 준비(적금 vs 투자)**를 직접 모델링하고 시뮬레이션해보는 Vanilla JS 기반 금융 교육 웹 애플리케이션입니다. 

교실 환경의 전자칠판에 띄우는 **교사용 대시보드(실시간 드림 월/워드 클라우드)**와 **학생용 개인 포털**이 실시간으로 동기화되어 상호작용 학습이 가능합니다.

---

## 🌟 주요 핵심 기능

### 1. 🎯 드림보드 설계 (8대 카테고리 & AI 비용 추산)
* **8개 카테고리 (4x2 그리드)**: 여행 ✈️, IT/쇼핑 💻, 주거 🏠, 경험 🎓, 자동차 🚗, 자기개발 🎨 외에도 **`건강/스포츠 🏃`** 및 **`가족/기부 💝`** 카테고리를 제공하여 나눔과 건강한 삶에 대한 가치를 다룹니다.
* **지능형 AI 비용 분석**: 학생들이 입력한 버킷리스트 키워드를 분석하여 현실적인 원화 기준 필요 예산 범위, 3대 세부 지출 항목 분할, 맞춤형 재무 조언 팁을 실시간으로 추산해 줍니다.

### 2. 🌊 현실 점검 (Reality Check - 수조 채우기 게임)
* **소득 상승률 슬라이더**: 고정 월급이 아니라 연평균 소득 상승률(0~8%)을 조절하여 물가 및 임금 성장을 체감하고 이에 따라 드림 저축액이 동적으로 증가하는 복리 모델을 지원합니다.
* **커스텀 고정비 입력**: 프리셋 지출 카드(식비, 주거비 등) 외에 개인이 직접 기타 월 고정 지출을 추가하고 삭제할 수 있어, 개별 가계 상황에 맞춘 정밀 설계가 가능합니다.
* **현금 흐름 수조**: 수입(물 유입)과 지출(물 유출)의 관계를 수조 내부의 물 높이와 애니메이션 파도로 구현하여 재무 적자/흑자 상태를 시각적으로 보여줍니다.

### 3. 🏁 자산 증식 60년 레이싱 (20세 ~ 80세)
* **예적금(연 2%) vs 분산 투자**: 복리의 효과로 인한 최종 은퇴 자산 격차를 레이싱 경기장의 러닝 마커와 그래프로 실시간 중계합니다.
* **국민연금(월 80만 원) 하한선 수식**: 은퇴 나이 이후 근로소득 중단 시 국가 복지 혜택인 국민연금이 자동으로 들어와 노후 인출 부담을 덜어주는 보정 로직을 포함하고 있습니다.

### 4. 🖥️ 교사용 실시간 대시보드 (Live Dream Wall)
* **실시간 드림 월**: 반 학생들이 추가한 꿈 카드(학생 이름, 꿈의 내용, 나이, 목표 비용)가 실시간으로 통통 튀며 대시보드에 공유됩니다. 친구들의 꿈을 참고하여 본인의 드림보드를 수정하는 **동료 학습**에 최적화되어 있습니다.
* **워드 클라우드**: 반 전체의 버킷리스트 키워드 빈도를 spiral collision알고리즘으로 캔버스 상에 입체적으로 요약 시각화합니다.
* **데모 학생 인젝션**: 수업 전 시연을 돕기 위해 15초 단위로 단계별 시뮬레이션을 도는 5명의 가상 학생 데이터를 주입할 수 있습니다.

### 5. 📄 수행평가용 보고서 다운로드 및 인쇄
* 시뮬레이션 종료 시 학생의 재무 설정 및 성공률, 시뮬레이션 결과가 예쁘게 정리된 단독 HTML 보고서 파일이 다운로드됩니다.
* 해당 파일을 열면 **즉시 인쇄 대화상자(`Ctrl + P`)가 팝업**되도록 설계되어 수행평가 증빙 및 출력에 탁월합니다.

## 🛠️ 기술 스택
* **Front-end**: HTML5, Vanilla CSS, Vanilla JavaScript (ES6+)
* **Back-end/Sync**: Firebase Firestore SDK (Compat Mode) / LocalStorage & BroadcastChannel (Offline Demo Mode)
* **AI Engine**: Google Gemini 1.5 Flash API (API Key 연동 시 작동)

---

## 🚀 시작하기 & 로컬 실행

이 프로젝트는 웹 서버 환경에서 정상 작동합니다 (Firebase 및 Gemini API 비동기 fetch 호출 목적).

### 1. 로컬 웹 서버 실행 (Python 예시)
프로젝트 루트 폴더에서 아래 명령어를 실행하여 로컬 서버를 켭니다.
```bash
python -m http.server 8000
```
그 후 브라우저에서 `http://localhost:8000`으로 접속합니다.

### 2. 오프라인 데모 모드 (Firebase 없이 실행)
1. 교사용 대시보드로 입장하기 클릭 ➡️ PIN 번호 `1234` 입력.
2. 우측 상단의 `⚙️ Firebase 설정` 클릭 ➡️ **`Offline 데모 모드로 실행`** 클릭.
3. 데이터베이스 연동 없이 로컬 스토리지 브로드캐스트 기반 오프라인 모드로 즉시 실행됩니다.

### 3. API 키 연동 (선택 사항)
* `⚙️ Firebase 설정` 메뉴에서 Firebase Configurations JSON 객체와 Gemini API Key를 저장하면 실시간 클라우드 DB 연동 및 AI 비용 예측 엔진을 온전히 활용할 수 있습니다.
